AppCore Technologies - Logo Kit
================================

Two colour versions, both official. Use whichever fits the place:
  Blue    - AppCore brand blue. ERP products, letterheads, social media, general use.
  Copper  - Carbon & Copper. AppCore website and Console, premium print, signage.
  Mono    - one colour (black / white) for stamps, embossing, fax, engraving, watermarks.

Folders (inside Blue, Copper and Mono)
  SVG\      vector master files - use these for print, signboards, designers (any size, never blurry)
  PNG\      ready-made pictures with transparent background, in several sizes (size is in the file name)
  Favicon\  favicon.ico, favicon.svg, apple-touch-icon.png, icon-192.png, icon-512.png (website tab icons)

Versions
  Horizontal  - mark + name side by side. Default for headers, invoices, email signature.
  Stacked     - mark above the name. Square spaces: profile pictures, cover pages, shop front.
  Mark        - the AC symbol only. Small spaces.
  AppIcon     - the mark on a rounded dark tile. Phone / desktop icon, browser tab.
  "for-light-bg" = put it on white or light backgrounds.
  "for-dark-bg"  = put it on black, navy or dark photos.

Colours
  Blue    : A gradient #3FA2FF > #1F6BFF > #0A3FD6   lines #1F6BFF   tile navy #0A1230
  Copper  : A gradient #F3B385 > #C8703A > #7A3410   lines #B4551F   tile carbon #1A1E27
  Ink (C and CORE on light) #1D2230      on dark: #F3F5FA (blue) / #F3F0EA (copper)

Rules
  - Do not stretch, rotate, recolour, add shadows or outlines.
  - Keep clear space around the logo at least the height of the "A" in APPCORE.
  - Smallest size: horizontal 120 px wide (25 mm in print); mark 16 px.
  - Text "TECHNOLOGIES" is already converted to shapes; no font is needed.
