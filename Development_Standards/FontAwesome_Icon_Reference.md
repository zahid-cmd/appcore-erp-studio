# AppCore Studio - Font Awesome Icon Reference

This document is the official Font Awesome icon standard for the AppCore Studio ERP Framework.

> **Version:** Font Awesome 6 Free

---

# General Standards

- Use **Font Awesome 6 Free**
- Prefer **Solid (`fas`)** icons.
- Use one icon consistently for one business entity.
- Do not introduce new icons without updating this document.
- Always reuse the existing standard icon before selecting another.
- Keep icon usage consistent across Backend Studio, Frontend Studio and generated modules.
