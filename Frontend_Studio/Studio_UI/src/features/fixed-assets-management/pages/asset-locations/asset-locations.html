About Locations
What a location is for
  • A location is a place inside a branch : a room, a floor, a store.
  • An asset card can name the location where the asset is kept.
  • An Asset Transfer moves an asset from one location to another.
  • The physical count (Asset Verification) is done location by location.
  • The branch of a location that holds assets cannot be changed.
